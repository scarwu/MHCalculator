## Development

### Install Env Tools

~~~
sudo npm -g install gulp-cli yarn
~~~

### Install Packages

~~~
./setup.sh
~~~

### Generate Folder for Dev

web root path please set to ./src/boot

~~~
gulp # live reload

# or

gulp prepare # for 1 time check
~~~

## Deploy Github Page

~~~
gulp release # and commit to github
~~~
